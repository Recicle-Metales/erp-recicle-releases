# ERP Recicle — Descargas

Repositorio público para distribuir instaladores y actualizaciones oficiales de ERP Recicle.

## Estado actual

Todavía no hay una versión instalable publicada. Las primeras entregas se identificarán claramente como versiones de prueba.

## Canales previstos

- **Beta:** validación funcional y pruebas con usuarios.
- **Estable:** versión autorizada para operación.

Los instaladores se publicarán en la sección **Releases** de este repositorio. El código fuente permanece bajo propiedad de Recicle Metales en un repositorio privado.

> No utilice archivos redistribuidos por terceros. Descargue únicamente versiones publicadas por la organización Recicle-Metales.
